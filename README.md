# CISSP Study Guide & Resources 🛡️

Welcome to this repository dedicated to preparing for the (ISC)² Certified Information Systems Security Professional (CISSP) certification exam! This collection includes study notes, resources, links, tips, and potentially practice questions compiled during my own study journey (or as a collaborative effort).

**Goal:** To provide a structured and helpful resource for fellow CISSP aspirants navigating the vast landscape of information security concepts covered by the exam.

**Disclaimer:** This repository contains personal study notes and curated resources. It is **not** an official (ISC)² resource and is not affiliated with (ISC)². While effort has been made to ensure accuracy, there is no guarantee of completeness or correctness. Always refer to the official (ISC)² CISSP Common Body of Knowledge (CBK), Official Study Guide (OSG), and other official materials as your primary sources. Passing the exam depends on individual effort, understanding, and experience.

## Contents 📚

This repository may include:

* **Resource Links:** Curated links to helpful articles, videos, tools, blogs, and official documentation.

## How It's Organized 📂

The content is primarily structured around the 8 CISSP Domains (as of the current CBK):

1.  **`Domain 1: Security and Risk Management`**
2.  **`Domain 2: Asset Security`**
3.  **`Domain 3: Security Architecture and Engineering`**
4.  **`Domain 4: Communication and Network Security`**
5.  **`Domain 5: Identity and Access Management (IAM)`**
6.  **`Domain 6: Security Assessment and Testing`**
7.  **`Domain 7: Security Operations`**
8.  **`Domain 8: Software Development Security`**

Additional folders might include:

* **`_Resources/`**: General links, tools, and external materials.
* **`_Practice_Questions/`**: Links or notes related to practice exams.
* **`_Study_Plans/`**: Templates or examples.
* **`_Tips_and_Tricks/`**: General advice.

## How to Use This Guide 💡

1.  **Clone or Fork:** Clone this repository to your local machine (`git clone <repo-url>`) or fork it to your own GitHub account to modify it.
2.  **Navigate by Domain:** Use the folder structure to focus on specific domains you are studying.
3.  **Supplement, Don't Replace:** Use these notes as a *supplement* to official study materials (like the OSG), video courses, and practice exams.
4.  **Active Recall:** Don't just read the notes passively. Use them as prompts to recall information actively. Test yourself frequently.
5.  **Contribute (Optional):** If you find errors, have better explanations, or useful resources, consider contributing! (See Contributing section below).
6.  **Check Official Sources:** The CISSP CBK can change. Always verify information against the latest official (ISC)² materials.

## Recommended Core Resources 🌐

While this repo aims to be helpful, these are generally considered essential:

* **(ISC)² Official Study Guide (OSG):** The primary textbook.
* **(ISC)² Official Practice Tests:** Crucial for gauging readiness and understanding question style.
* **Video Courses:** Popular options include those by Kelly Handerhan (Cybrary), Thor Pedersen (Udemy), Mike Chapple (LinkedIn Learning/CertMike), Pete Zerger (YouTube).
* **Community:** Reddit's r/cissp is an invaluable resource for tips, experiences, and support.
